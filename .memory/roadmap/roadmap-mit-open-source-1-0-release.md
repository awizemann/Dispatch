Dispatch is being prepared for its first public, MIT-licensed release. The app itself is feature-complete for v1 (bus core, repo install, projects rail, message center, bus map, notifications); the remaining work is entirely repo hygiene and public-readiness, tracked as the OSS-P1..P8 arc in TASKS.md.

## Observations
- [fact] Release arc covers: source-code residue scrub from the prior internal prototype, dev-config and repo hygiene, Memophant tier content scrub (this task), a rewritten public wiki, public root docs and community health files, a marketing site, an integration audit + full-tree leak sweep, and finally collapsing git history to one clean commit before Alan's push #plan
- [constraint] Nothing about the prior internal prototype this app was extracted from may appear in anything that ships publicly — source, docs, memory notes, or design assets #constraint
- [todo] Post-1.0 candidates (not yet scheduled): richer bus-map interactions, additional notification channels, and any feature work that surfaces once real external users start linking projects #future
